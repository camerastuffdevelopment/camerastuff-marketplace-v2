### 3. Special Notes

- **NEXT_PUBLIC_API_URL**: Points to Railway backend. Must include `https://` protocol
- **NEXTAUTH_URL**: Your Vercel domain. Critical for NextAuth callbacks to work
- **NEXTAUTH_SECRET**: Must match exactly (already secured on Railway)
- **RESEND_API_KEY**: Get from https://resend.com/api-tokens (free tier, 3k/month)

## Troubleshooting

### NextAuth Errors
- Verify `NEXTAUTH_URL` matches your actual Vercel domain exactly
- Check `NEXTAUTH_SECRET` matches exactly (no typos)
- Clear browser cookies and cache if getting auth errors

### API Connection Errors
- Verify `NEXT_PUBLIC_API_URL` includes `https://` protocol
- Check backend is still running on Railway
- Check CORS configuration on backend (should allow Vercel domain)

### Build Failures
- Re-check all environment variables for typos
- Redeploy using the Vercel UI (don't push code unless fixing bugs)
